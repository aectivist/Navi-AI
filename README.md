# NAVI AI ASSISTANT
Inspired by Serial Experiment Lain's COPLAND OS and NAVI computers, NAVI is an AI chatbot created for the purpose of both entertainment and home lab assistance. 

# FUNCTIONS
**1. DISCORD BOT**
NAVI is a discord bot able to send and receive messages within servers, and has the ability to call when asked. (STILL W.I.P for refactoring and management, but it works)

**2. VTUBER**
NAVI uses vseeface's interface to provide visualisation as she communicates with you, allowing the user to change her appearance based on whatever you want, as long as you have a vrm provided. However, do note that virtual microphones must be bought in order to be used.

**3. TASK FUNCTIONS**
Depending on what functions you give it, it will be able to do things for you. Currently the highlighted functions it has are checking the stock, the weather, and code creation. More functions will be implemented in the near future. 

**4. STANDALONE COMMUNICATION**
Even without an interface, NAVI still functions alone, with a full bot system. NAVI uses python's speech recognition algorithm to detect if the word "NAVI" was said, openAI's Whisper for speech to text, Meta's Ollama for the AI, and coquiTTS for text to speech.
